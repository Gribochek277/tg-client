message:
Fix inline images, message order, Esc handling, Tab focus, media cache
Images:
- Root cause of 'photos never display': readImageSize only read 128 header
  bytes, so EXIF-heavy JPEGs returned null and the download was never
  cached (placeholder stuck on 'loading…'). Header read bumped to 1MB;
  dimension reads made exception-safe.
- Persistent disk cache: media now lives in ~/.local/share/tg-client/media/
  (not /tmp) with chatId_msgId filenames (no cross-chat collisions).
  Restarts reuse the cache (no re-download).
- Prefetch only the 5 newest pictures; older ones download on demand when
  they scroll into view (on-visible-media hook). Failed downloads are
  remembered so the per-frame hook can't retry them forever.

Message order:
- iterMessages yields newest→oldest; the list is now reversed so the chat
  renders oldest→newest with the newest pinned to the bottom.

Keys/focus:
- Bare ESC never resolved in the key parser (buffered until the next key,
  merging Esc+Tab into Alt+Tab). A lone ESC now times out after 80ms and
  resolves as Escape — Esc, then Tab, then j/k work as expected.
- Sidebar navigation verified (Tab cycle sidebar↔pane, j/k select, Enter
  opens); the earlier dead-feeling Tab was the connect hang leaving an
  empty dialog list — connect now runs in the background with retries.

Also: message view background uses the sidebar theme color (was fg).
