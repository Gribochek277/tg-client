Add Neovim-style mode system: command-line (:), search (/ ?), :q exit
Replaces /slash commands with a Neovim mode machine:
- normal: navigation (j/k/h/l/f/o), mode entry via :, /, ?
- insert: composer (i/Enter/Esc)
- command: bottom : line with Tab-cycling completion, keep-on-error
- search: / forward, ? backward, wrap-around, n/N repeat

:q quits (Ctrl+Q kept as emergency alternative); last command line is
recalled between invocations. Docs (README, PRD, main.ts --help)
updated; AGENTS.md now limits screenshots to image features.
