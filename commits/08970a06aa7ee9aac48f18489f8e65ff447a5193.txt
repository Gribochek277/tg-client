Add server-side message search (:search <query>)
TgClient.searchMessages() runs messages.Search via iterMessages({search}).
:search replaces the message view with results: header shows
"🔍 query — N results (n/N, Esc)", n/N step through results, Esc or an
empty :search restores the normal chat. Search-results views are guarded
against live reloads and reset on chat switch/send. Media cache is
scanned for results too.
