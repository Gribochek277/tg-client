Add desktop notifications for new messages (notify-send)
Incoming 'new' updates notify via notify-send (mako/dunst daemon):
- title = chat name, body = first 120 chars of the message text
- skips the chat open in the focused pane and muted chats
- 1.5s burst collapse per chat (albums)
- async spawn, stdio ignored — the TUI never blocks and stdout stays clean
- disabled via notifications:false in config.json (default on)
- outgoing updates are filtered upstream (out flag)
